# MyGo Uke · UI 方向稿

打开 `index.html` 查看。全部离线自包含，不依赖 React、CDN 或任何图片资源。

## 文件

- `index.html` — 设计稿主页面：三个主界面方向、竖屏/横屏输出画框、三个关键状态、交互说明。
- `styles.css` — 应用界面与设计画布的样式；三个方向通过 `theme-studio` / `theme-songbook` / `theme-daylight` 切换 token。
- `app.js` — 画板缩放、尤克里里指法图、时间轴波形、播放头、安全区与小型交互。

## 三个方向

- **A · 录音棚（推荐）**：深色外壳，暖琥珀只给当前拍点和主动作。视频是唯一亮面，适合长时间校对。
- **B · 歌本**：纸面、宋体、朱砂红。更接近发布物，但控件对比度弱于 A。
- **C · 日光工作台**：浅色、浮起卡片、青绿色强调。更接近 macOS 原生工作台。

## 已定的界面约束

- 窗口基准 1440 × 900，主输出 1080 × 1920。
- 竖屏输出：顶部 4% 留空，和弦条 6–11%，字幕约 70%，右侧 120px 与底部 15% 为安全区。
- 横屏输出：人像 607 × 1080 居中，左右各 656px；左侧当前和弦/指法，右侧完整弹唱谱。
- 和弦条只显示当前 + 接下来 1–2 个，不铺整页谱。
- 字幕与和弦共用同一套叠加层；播放头同时驱动预览、字幕高亮和小节高亮。

## 交互试玩

- 主界面画板里的播放按钮、时间轴、工程列表、节奏型、字幕卡片、竖/横屏分段都可点。
- 点「安全区」显示/隐藏竖屏输出的安全线。
- 和弦选择与导出画板里的选项可点选。

## 已选方向

**A · 录音棚**。实现落在 `app/internal/app/`：

- `theme.go` — 设计 token，对应本文的 `theme-studio`
- `ui_shell.go` — 标题栏、工程列表、状态栏
- `ui_stage.go` — 预览画布、和弦条、指法图、字幕、时间轴
- `ui_inspector.go` — 字幕 / 和弦 / 样式检查器
- `ui_modal.go` — 分析、和弦选择、导出

设计稿仍然是视觉基线；Go 视图遵循同一套间距、层级与安全区。
