MyGo Uke · Interface direction 01

把一首弹唱，
校成一条能发的片子。

界面围绕一件事：让播放头成为唯一焦点。预览、字幕、和弦、小节高亮都由它驱动； 用户不需要理解时间轴细节，只需要在听到不对的地方停一下、改一下。

设计前提

  • 单用户、鼠标/触控板、长时间校对
  • 竖屏是发布主路径，横屏是跟练形态
  • 视频不出本机，只有压缩音频上传
  • 所有输出安全区按平台硬约束预留

信息层级

  • 第一层：视频画面与当前字幕
  • 第二层：当前和弦、下一两个和弦
  • 第三层：时间轴、待确认项、工程列表
  • 主动作只有一个：导出成片

视觉系统

没有现成品牌系统。以「录音棚 + 歌本」为基调：暖琥珀只标记当前拍点与主动作， 其余控件退到墨色和灰阶。中文用苹方，标题与谱面用宋体形成印刷感。

01 · Main desk

主界面方向

同一套布局骨架，三种气质。A 把视频推前、工具退后；B 让歌词像摊开的歌本； C 更接近 macOS 白天的原生工作台。

A 录音棚 推荐 暖琥珀只给当前小节和主动作。深色外壳让视频成为唯一亮面，适合一小时以上的校对。
1440 × 900 · 校对台默认态 点击画板里的工程、节奏型、竖/横屏可试状态
B 歌本 纸面、宋体、朱砂红。更接近「发布物」而不是「剪辑软件」，但控件对比度会弱一些。
1440 × 900 · 歌词优先的校对台 和弦名用衬线体，像印在谱面上
C 日光工作台 更轻、更接近 macOS 原生面板。视频仍然居中，但浮起的卡片让界面多一层「工具感」。
1440 × 900 · 白天/浅色环境 青绿色替代琥珀，适合长时间浅色阅读

04 · Interaction notes

交互说明

这些是 M2 校对台必须成立的五个动作。任何一条不成立，界面就会退化成「带时间轴的表格」。

播放头联动

拖动时间轴，预览帧、字幕卡片、小节高亮同时更新。播放时用 30ms 轮询，不用低频事件。

点小节改和弦

点时间轴上的小节，弹出常用和弦矩阵。应用后立即重排指法图和当前和弦条。

逐句改字幕

点字幕卡片跳转到对应时间，直接改文字。改完不需要「保存」，工程自动落盘。

竖/横屏切换

只切换预览布局和导出目标，不重置工程。横屏的谱面滚动跟随同一播放头。

导出可后台

导出放独立渲染进程，关掉进度面板也继续跑。完成后再通知，不阻塞下一首。

待确认优先

低置信度小节、不可弹和弦、小节边界可疑，都汇总到状态栏，点一下跳到对应位置。
